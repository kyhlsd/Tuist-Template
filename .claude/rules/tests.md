# 테스트 규약

- 새 테스트는 Swift Testing(`@Test`, `#expect`, `#require`)으로 작성합니다.
  기존 XCTest 파일을 수정할 때는 그 파일의 스타일을 따릅니다.
- 테스트 이름은 `동작_조건_기대결과` 형태로 무엇을 검증하는지 드러냅니다.
- 한 테스트는 하나만 검증합니다. 단언이 다섯 개를 넘으면 쪼갭니다.
- 네트워크·디스크·시계에 의존하지 않습니다. 모두 테스트 더블로 대체합니다.
- `sleep`이나 고정 대기를 쓰지 않습니다. 비동기는 `await` 또는 확인 지점으로 동기화합니다.
- 테스트 실패를 `XCTSkip`이나 주석 처리로 회피하지 않습니다. 고치거나 남겨둡니다.
